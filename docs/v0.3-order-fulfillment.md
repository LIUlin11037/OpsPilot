# OpsPilot v0.3 订单履约追踪

按精确订单 ID 查询受理、库存预留和发货三个检查点。示例程序写入隔离目录中的三个 SQLite 库。OpsPilot 用只读连接读取它们，并把诊断报告另存到同一目录下的报告库。该示例从可运行的业务操作生成记录，可在本机离线复跑。

## 适配器契约

HireHub 先通过业务记录解析消息 ID，再读取事件分支。Voting 用投票人 ID 回放 Redis 和 PostgreSQL 的观测。订单适配器用同一个订单 ID 在三个来源分别查询匹配的记录。三者共用 `TargetTraceSource` 和 LangGraph 追踪流程。

| 契约项 | 订单适配器 |
| --- | --- |
| 关联标识 | `--order-id` 传入原始字符串。查询绑定该字符串，使用区分大小写的精确匹配。 |
| 检查点 | `order_accepted` 查 `orders`，`stock_reserved` 查 `inventory_reservations`，`shipment_created` 查 `shipments`。各表应提供 `order_id TEXT` 列。 |
| 证据 | 每项保留数据库 URI、表名、观察时间和查询结果。单项查询失败时记录来源和原因，继续读取其他独立来源。 |
| 状态 | 查询成功且有匹配行是 `observed`，成功且零行为 `not_observed`，读取失败为 `unknown`。整体原因保持 `undetermined`，供后续排查。 |

使用其他部署时，将样例中的 `environment` 和三个数据库路径改为实际来源。相对路径按目标配置所在目录解析。订单专属表和查询集中在订单适配器，目标配置和 CLI 负责注册入口。

## 复现

在仓库根目录运行以下 PowerShell 命令。每次使用新目录，三个业务数据库、目标配置和报告库都在该目录下。

```powershell
$python = ".\.venv\Scripts\python.exe"
$work = Join-Path ".opspilot" ("order-fulfillment-" + [guid]::NewGuid().ToString("N"))
& $python examples/order_fulfillment_demo.py --work $work seed
$target = Join-Path $work "target.json"
$db = Join-Path $work "reports.sqlite3"
Copy-Item examples/order-fulfillment-target.json $target
$trace = @("diagnose-auto", "--config", $target, "--order-id", "ORD-0042", "订单履约进展")

& $python -m opspilot --db $db @trace --plan

# 发货源不可读取，受理和预留仍可观测。
$unavailable = & $python -m opspilot --db $db @trace | ConvertFrom-Json

# 发货源可读，其中只有另一张订单的发货记录。
& $python examples/order_fulfillment_demo.py --work $work restore-shipping
$pending = & $python -m opspilot --db $db @trace | ConvertFrom-Json

# 目标订单完成发货。
& $python examples/order_fulfillment_demo.py --work $work ship
$shipped = & $python -m opspilot --db $db @trace | ConvertFrom-Json

foreach ($result in @($unavailable, $pending, $shipped)) {
    & $python -m opspilot --db $db report $result.task_id --format markdown
}
```

| 阶段 | 受理 | 库存预留 | 目标订单发货 |
| --- | --- | --- | --- |
| 发货库尚未建立 | `observed` | `observed` | `unknown`，报告来源及 `source_query_failed`。 |
| 发货源恢复可读 | `observed` | `observed` | `not_observed`，查询成功且只匹配零条。 |
| 目标订单发货后 | `observed` | `observed` | `observed`，一条匹配记录。 |
