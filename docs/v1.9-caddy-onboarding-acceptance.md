# v1.9 Caddy 全链路接入验收

用原版 Caddy 网关和上游复现 HTTP 故障。网关的结构化访问日志、Prometheus 抓取的指标和 Jaeger 收到的跨度都来自同一批真实请求。OpsPilot 通过已有配置和只读查询取证。 [首次接入指南](first-caddy-onboarding.md)

## 隔离环境与复现

在仓库根目录使用已安装的 OpsPilot 和正在运行的 Docker。示例的 HTTP、Prometheus 与 Jaeger 查询端口只映射到本机回环地址。上游状态切换仅发生在示例容器内。每次使用新的输出目录。

```powershell
docker compose -p opspilot-v19-caddy -f examples/caddy-onboarding/compose.yaml up -d --wait
python examples/caddy-onboarding/acceptance.py capture .opspilot/caddy-acceptance
docker compose -p opspilot-v19-caddy -f examples/caddy-onboarding/compose.yaml down --volumes
python examples/caddy-onboarding/acceptance.py compare .opspilot/caddy-acceptance
```

`capture` 保存转换前后的日志、Prometheus 原始范围响应、按 Trace ID 查询的 Jaeger 原始数据、计划和 SQLite 报告。`compare` 保存三组 JSON、Markdown 和 `verification.json`。如需独立接入验收，在关闭容器前只交接指南、读接口、`handoff.json` 和 `gateway-raw.jsonl`。
