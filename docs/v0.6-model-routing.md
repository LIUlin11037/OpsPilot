# OpsPilot v0.6 可选模型辅助选路

规则仍是默认入口，启动、计划预览和诊断无需模型服务。可选助手只在规则无法选路时，从当前配置已有的 `http_health` 和 `queue` 中建议一个流程。明确指定流程、业务 ID、消息 ID 或强制检查时，沿用相应入口。

模型请求中的故障数据是用户输入的问题原文和可选流程的名称及说明。程序把目标配置、队列名、诊断凭据、报告、日志和业务证据留在本地。写进问题里的信息会随原文发送。有效建议必须是仅含 `workflow` 的 JSON 对象，值为一个已配置流程或 `null`。来源、检查条件和诊断预算均由正常程序路径根据原配置生成。

## 跑同一组选路评测

内置 24 条事先标注的中英文合成描述，覆盖明确规则命中、改写、混合症状、证据不足、写操作请求、配置缺失以及明确的排查侧重。正确和错误选路只统计实际选出的流程，弃权单独计数。评测记录每条结果、请求耗时及服务返回的 token 用量。

```powershell
$python = ".\.venv\Scripts\python.exe"
& $python -m opspilot evaluate-routing --rules-only

$env:OPSPILOT_ROUTER_URL = "http://127.0.0.1:18763/v1/chat/completions"
$env:OPSPILOT_ROUTER_MODEL = "qwen2.5-0.5b-instruct-q4_k_m"
& $python -m opspilot evaluate-routing | Set-Content -Encoding UTF8 .opspilot/routing-evaluation.json
```

模型服务需支持对话完成接口和 JSON 输出。本机 HTTP 模型可省略密钥。远端模型使用 HTTPS，凭据从 `OPSPILOT_ROUTER_API_KEY` 读取。可用 `OPSPILOT_ROUTER_TIMEOUT_SECONDS` 调整默认 10 秒的套接字超时。请求最多带入 2,048 字符的问题，并将生成上限设置为 48 个 token。

## 启用条件

在同一批案例上，正确选路增加且错误选路不增加才算通过。评测报告绑定内置测试集、协议版本、模型名和端点。更换部署的模型权重时应重新评测。

```powershell
& $python -m opspilot diagnose-auto --config target.json --model-routing .opspilot/routing-evaluation.json "浏览器请求一直等不到响应"
```

没有有效评测、模型配置缺失、模型超时、弃权或返回无效及越界建议时，命令保留规则的澄清提示。规则已能选路时直接使用该结果。成功采用建议的报告记录模型名、发送的数据字段、调用耗时和可获得的 token 用量。

## 本机真实模型验收

2026 年 11 月 24 日，用 llama.cpp Windows CPU 构建 `b11887` 和 Qwen2.5-0.5B-Instruct 的 `Q4_K_M` 权重执行同一套评测。权重从 Qwen 的 ModelScope 仓库下载，SHA-256 与官方 Hugging Face 发布值 `74a4da8c9fdbcd15bd1f6d01d621410d31c6fc00986f5eb687824e7b93d7a9db` 一致。[llama.cpp 构建校验](https://github.com/ggml-org/llama.cpp/attestations/59670438) · [Qwen 权重校验](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct-GGUF/blob/main/qwen2.5-0.5b-instruct-q4_k_m.gguf)

复现时用同版本启动本地服务，参数为 `--host 127.0.0.1 --port 18763 --alias qwen2.5-0.5b-instruct-q4_k_m -c 1024 -t 4 --parallel 1 -ngl 0`，用 `-m` 指定校验过的权重。启动后按上面的评测命令运行。本次模型评测套接字超时设为 15 秒。

| 路径 | 正确选路 | 错误选路 | 弃权 | 正确弃权 |
| --- | ---: | ---: | ---: | ---: |
| 规则 | 4 | 0 | 20 | 13 |
| 规则加 Qwen 辅助 | 9 | 11 | 4 | 4 |

Qwen 共被调用 17 次，累计请求耗时约 5.05 秒，累计输入 2,652 token、输出 151 token。推理在本机 CPU 运行。新增正例主要来自 HTTP 改写，错误集中在把混合症状、信息不足、写操作请求和部分队列症状选成 HTTP。**该模型未通过启用门槛**，运行时使用实际评测文件验证了拒绝启用，规则预览仍可离线使用。完整逐项结果位于本地 `.opspilot/model-evaluation/qwen-routing-evaluation.json`。

受控测试使用本机模拟接口，分别覆盖合格模型进入已配置流程、无模型配置、有明确规则、无效或越界建议、超时、缺远端密钥和未达评测门槛。模拟接口的结果用于验证程序行为。

`python -m opspilot` 启动成功，默认 `python -m pytest` 通过 362 项，跳过默认关闭的 5 项。
