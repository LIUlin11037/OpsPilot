# v1.5 离线诊断回归

在已安装 OpsPilot 的 Python 环境中，从仓库根目录运行下列命令。也可以在其他目录运行同一个脚本的绝对路径。

```powershell
python examples/diagnostic-regression/run.py
```

回归使用本机回环地址提供固定响应。每个案例会生成临时目标配置和 SQLite，用 `diagnose-auto` 执行诊断，再按原任务 ID 使用 `report` 回读。子进程只允许访问它自己的本机测试服务。运行不需要模型密钥、真实服务或 Docker。

结果为逐案 JSON。`passed` 给出整次运行和单个案例的判定。若诊断正常结束但报告偏离预期，失败的检查会包含 `field`、`expected` 和 `actual`，并区分字段缺失与 `null`。诊断命令本身失败时，案例会保留其错误。任一案例失败，进程返回 1。`--cases` 可指定测试使用的案例副本。[案例字段与数据来源](../examples/diagnostic-regression/README.md)

## 2026-11-27 离线验收

在新建 Python 3.10 虚拟环境中离线安装已有依赖，从独立目录加载本轮源码。移除模型与跟踪配置，并用回归入口限制子进程只能访问当前案例的回环地址。两次独立运行的 JSON 一致。首轮 14.36 秒，共 **6 个案例、196 项检查通过**。

| 案例 | 来源 | 核验结果 |
| --- | --- | --- |
| `healthy` | Traefik 健康基准 | HTTP 200，`no_failure_observed`。 |
| `http-fault` | Traefik 故障观测 | HTTP 504，5xx 占比峰值 100%，p95 峰值 1.155 秒。根因为 `undetermined`。 |
| `recovered-history` | Traefik 恢复与历史观测 | 当前 HTTP 200。历史窗口有两条样例错误，两项指标均超过阈值。异常引用 `[1, 2, 3]`。 |
| `history-source-timeout` | 模拟 | 保留健康探针和已读日志，指标 `query_timeout`。缺口索引 `[2]`，历史判断为 `undetermined`。 |
| `scope-isolation` | 模拟 | 同时间的相邻服务错误和目标服务窗口外错误均被排除。目标窗口只匹配一条正常日志。 |
| `unrelated-message` | 模拟 | 目标消息查询成功且零匹配。队列有积压，处理证据不包含其他消息 ID 或其失败结果。 |

将 `healthy` 副本的预期状态改为 `undetermined` 后，诊断与回读仍成功。回归指出 `status` 的实际值为 `no_failure_observed`，退出码为 1。首轮核验还发现比较器曾区分数值 `1` 和 `1.0`，已按 JSON 数值语义修正。本批案例的诊断结论与预先标注的观测一致。

独立复核补测了混合服务范围的指标查询，以及临时目录创建和清理失败。固定响应服务会拒绝样例中的错范围查询，目录失败会保留案例 ID 和错误，后续案例仍继续执行。修复后用同一干净环境重跑两次，196 项检查继续通过，受控差异仍返回 1。
