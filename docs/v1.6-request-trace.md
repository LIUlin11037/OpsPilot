# v1.6 按 Trace ID 追踪请求

在目标配置中填入 Jaeger 2 查询服务的基址。连接器使用公开的 v3 HTTP JSON 接口读取一个已知 Trace ID。需要鉴权时，通过 `OPSPILOT_JAEGER_TOKEN` 提供查询端接受的 Bearer 令牌。带令牌的查询使用 HTTPS 或本机回环 HTTP。[Jaeger 查询接口](https://www.jaegertracing.io/docs/2.23/architecture/apis/)

```json
{
  "jaeger": {"base_url": "http://127.0.0.1:16686", "timeout_seconds": 5}
}
```

```powershell
python -m opspilot diagnose-auto --config target.json --trace-id TRACE_ID --plan "检查这次请求"
python -m opspilot diagnose-auto --config target.json --trace-id TRACE_ID "检查这次请求"
python -m opspilot report TASK_ID --format markdown
```

计划预览显示单次 GET、具体 Trace ID 和读取限制。默认超时 5 秒，配置上限 15 秒，返回量上限 4 MiB、1,024 段跨度。报告保留服务、操作、跨度 ID、父跨度、记录状态和时间。报告中的错误索引从 0 开始，可对应证据表中的原始记录。相连的上下游都报错时，报告将上游错误标为可能传播。多个独立异常会分开列出，业务根因保持待确认。

`linked` 表示返回的跨度可通过已知父子关系连成一条请求。`incomplete` 表示已有部分证据且存在缺口。`not_found` 表示后端返回无匹配记录，`unavailable` 表示读失败或无法建立可归属的跨度。判断以 Jaeger 实际返回的采样记录为范围。

## 本机验收

用一个以回环地址发布端口的 Jaeger 容器和两个示例 HTTP 服务。示例发起真实 HTTP 请求，携带 `traceparent` 在服务间传递请求标识，并向隔离 Jaeger 发送样例跨度。OpsPilot 只通过查询端口读取。以下命令使用 2.23.0，可将宿主端口替换为空闲端口。[Jaeger 单容器启动示例](https://www.jaegertracing.io/docs/2.23/getting-started/)

```powershell
docker run --detach --rm --name opspilot-jaeger-example -p 127.0.0.1:16686:16686 -p 127.0.0.1:4318:4318 cr.jaegertracing.io/jaegertracing/jaeger:2.23.0
python examples/jaeger-request-trace/acceptance.py --query-url http://127.0.0.1:16686 --otlp-url http://127.0.0.1:4318 --output .opspilot/jaeger-example
docker stop opspilot-jaeger-example
```

脚本使用新的输出目录。每次复跑会生成新的 Trace ID 和任务 ID，并保存 Jaeger 原始响应、JSON、Markdown、SQLite 和 `verification.json`。脚本逐条核对原始跨度的服务、状态、时间和父子关系，也会按任务 ID 回读报告。

2026-11-27 用 Jaeger `2.23.0` 隔离验收，容器镜像摘要为 `sha256:3823829974ccfc2485d2e48b165579091f32295022ae80ca49704e2f4834116e`。三个案例的原始观测和回读结果如下。

| 下游故障 | 502 / 503 | `ff69cc7a4fba486682282d7d8ae42fca` | `7387ad16-d9b4-43ab-9842-d337d9fb98e6` | 引用 orders 错误证据 `3`，gateway 的证据 `1` 和 `2` 位于同一路径。 |
| 缺失中间跨度 | 200 / 200 | `d989b9d6216444d59b6da9b154d48e48` | `44fbbe31-5764-4772-8ecd-0941a68bc26d` | 两段跨度可读，orders 的父跨度缺失，覆盖状态为 `incomplete`。 |
